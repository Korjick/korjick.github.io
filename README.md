# Bulat Fakhrutdinov — résumé

Резюме на Next.js 16 (App Router), React 19 и TypeScript

## Запуск

```sh
pnpm install
pnpm dev
```

Сайт: http://localhost:3000.

```sh
pnpm lint
pnpm build
```

Production-сборка создаёт статический сайт в `out/`. Для просмотра сборки используйте статический HTTP-сервер с корнем `out/`.
